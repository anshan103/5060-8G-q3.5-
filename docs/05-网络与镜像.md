# 05 · 网络与镜像实测（中国大陆环境）

这台机器在无代理的国内网络下。下面是逐个源实测的速度和坑，能省别人很多试错。

---

| `github.com` | ❌ 超时 | — | 网页和 git 都不通 |

## 二、最反直觉的一条：hf-mirror 不能用并发

用 6~10 路 `curl -r` 分片下载大文件，结果：

```
分片进程: 10 个
已下载: 0 MB
```

所有连接都卡在 0 字节，一个都不动。检查单个请求：

```
http=429 size=317
```

**被限流了。**

改成单流断点续传：

```powershell
curl.exe -sSL --retry 100 --retry-delay 8 --retry-all-errors -C - `
  -o model.gguf "https://hf-mirror.com/<repo>/resolve/main/model.gguf"
```

峰值能到 **6 MB/s**，5.54 GB 的文件两小时下完（中途速度会掉到 0.2 MB/s 然后再冲上去）。

**结论：hf-mirror 下大文件用单流 `-C -`，不要并发。**

## 三、GitHub 的正确用法

网页不通，但 `api.github.com` 通。可以这样拿发布资产：

```powershell
# 1. 查 release 列表，拿到 asset id
Invoke-RestMethod "https://api.github.com/repos/<owner>/<repo>/releases" -Headers @{'User-Agent'='Mozilla/5.0'}

# 2. 用 asset id 下载（Accept: application/octet-stream 会 302 到签名 URL）
curl.exe -sSL -H "Accept: application/octet-stream" `
  -o out.exe "https://api.github.com/repos/<owner>/<repo>/releases/assets/<id>"
```

**但速度只有 0.07~0.13 MB/s**，677 MB 要 90 分钟以上，基本不可用。
小文件（几 KB 的 SHA256SUMS）没问题。

## 四、GitHub 源码的替代路径

| 需求 | 可行方案 |
|---|---|
| 小文件（README、脚本） | `raw.githubusercontent.com` |
| 整个仓库 | HF 上的镜像 + 便携 git（见下） |
| 编译好的 release 资产 | 只能慢慢拖，或找国内镜像 |

### 用 HF 镜像克隆 GitHub 仓库

有些人在 HF 上建了 GitHub 仓库的镜像（`OpenTransformer/llama.cpp-prismml` 就是）。
HF 仓库本身就是 git 仓库，可以直接 clone：

```powershell
git clone --depth 1 https://hf-mirror.com/<user>/<repo>
```

注意必须禁 LFS filter（见 [03](03-llama.cpp编译.md) 的坑 2）。

## 五、便携工具从哪下

| 工具 | 来源 | 大小 |
|---|---|---|
| VS BuildTools 引导器 | `https://aka.ms/vs/17/release/vs_BuildTools.exe` | 4.3 MB |
| CMake | `https://cmake.org/files/v3.31/cmake-3.31.5-windows-x86_64.zip` | 46.6 MB |

> CMake 和 Ninja 其实 **VS BuildTools 装完就自带了**（勾 `VC.CMake.Project`），
> 上面这两个只有在你不想装 VS 时才需要。

## 六、Python 包

`pypi.org` 直连超时，但国内镜像正常：

```
https://pypi.tuna.tsinghua.edu.cn/simple/
https://mirrors.aliyun.com/pypi/simple/
```

要 CUDA 运行库请从 `developer.download.nvidia.com/compute/cuda/redist/` 下官方 zip。

## 七、夸克网盘

页面能读（带正常 UA 就能拿分享的 stoken 和文件清单），但：

- 匿名下载接口返回 404，**必须登录**
- 转存需要网盘有余量，配额满了会弹付费墙
- 客户端里已登录时，可以通过"转存 → 传输 → 下载"走，速度约 310 KB/s（非会员）

如果只是拿几个文件，比 GitHub 快；但如果配额满了，一点办法都没有。

---

## 八、给后来者的三条建议

1. **优先找国内镜像**（hf-mirror / npmmirror / 清华 / 阿里），能省 90% 的时间
2. **大文件用单流断点续传**，不要并发
3. **下载前先测速度**（`curl -r 0-1000000` 拿 1 MB 计时），别等半小时才发现 0.05 MB/s
